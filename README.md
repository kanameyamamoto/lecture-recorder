# LectureRecorder

大学の講義をメニューバーから録音して、Mac内で文字起こしし、テキストファイルとして保存するmacOSアプリです。
時間割を登録しておくと、今の授業・時限・第何回かを自動で入れてくれます。出席の記録も残せます。

- 録音も文字起こしも **Mac内で完結**（音声を外部のサーバーに送りません）
- 文字起こしの先頭に授業名・回数・日付などが入るので、AIでのまとめや別ツールへの取り込みにそのまま使えます
- パソコン版のGoogleドライブが入っていれば、文字起こしは自動でドライブに保存されます

## 活用例：講義メモから課題までを一続きに

このアプリ自体は「録音 → 文字起こし → 保存」までですが、外部サービスにつなげられるAIアシスタントと組み合わせると、講義の記録から課題の管理までを一続きにできます。

1. **Googleドライブ** をAIにつなぐ → このアプリが保存した文字起こしを読み取れる
2. **Google Classroom** をAIにつなぐ → その授業の配布資料や課題、締切を読み取れる
3. **Notion** をAIにつなぐ → 文字起こしと資料をもとに作った講義メモを、授業ごとのページに保存できる

たとえば「Inboxに新しい文字起こしがあれば、Classroomの資料と合わせて講義メモにまとめ、Notionに追加する」「授業中に口頭で出た課題も拾って、締切前にリマインドする」といった流れを、AIの定期実行の機能で自動化できます。
文字起こしの先頭に授業名・回数・日付が入っているので、AIがどの授業の第何回かを取り違えずに扱えます。

## 動作環境

- macOS 13 以降（macOS 26 以降なら、長時間の音声向けの新しい音声認識を使います）
- Xcode、または Command Line Tools（ビルドに使います）

## インストール

```
git clone https://github.com/kanameyamamoto/lecture-recorder.git
cd lecture-recorder
./build.sh
```

`~/Applications/LectureRecorder.app` ができて、メニューバーに角帽（🎓）のアイコンが出ます。録音中は塗りつぶしの角帽と経過時間に変わります。
「Swiftのコンパイラが見つかりません」と出たら、表示される画面で Command Line Tools をインストールしてから、もう一度 `./build.sh` を実行してください。

メニューの「ログイン時に起動」をオンにしておくと、毎回立ち上げる必要がありません。
初回の録音時に、マイク・音声認識・保存先フォルダへのアクセスの許可を求められます。

> メニューバーのアイコンが多いと、MacBookの画面上部の切り欠き（ノッチ）の裏に隠れて見えないことがあります。ほかのアイコンを減らすか、⌘を押しながらドラッグして右寄りに移動してください。

## 使い方

1. メニューの「時間割を編集…」で、曜日×時限のマス目に授業名を入れて保存
2. 授業が始まったら「● 講義の録音を開始…」
   - 確認画面に、日時・授業・時限・回数・出席数（前回までの出席 + 今回）が出ます
   - 授業と時限は時間割から、回数は「前回＋1」が自動で入ります。違っていればここで直して「録音開始」
3. 終わったら「■ 録音を終了して文字起こし」。完了すると通知が出ます

録音中に授業・時限・回数を間違えたと気づいたら、メニューの「録音中の情報を変更…」から直せます。録音をやめて音声ごと消したいときも、この画面の「録音を破棄」から行います（確認あり）。

ゼミやセミナーなど時間割に入らない録音は、時間割の編集画面の「フリー録音」に登録しておき、メニューの「● フリー録音を開始…」から種類を選んで録音します（時限・回数・出席はなし）。

### 録音しながらの文字起こし・字幕・翻訳

文字起こしは録音しながら行います（MixRec と同じ仕組み）。録音を終えるとすぐに保存され、各行に録音開始からの時間が付きます（`[00:12:34] …`）。

- マイクの音は Core Audio から直接受け取り、内蔵マイクがあれば内蔵マイクを使います（教室では、AirPods のマイクより机の上のMacの方が先生の声をよく拾うため）
- macOS 26 以降は SpeechAnalyzer（長い講義向けで、沈黙で止まらない）、それより前は SFSpeechRecognizer を使います
- 録音中の文字起こしが途中で止まっていた（10分以上なにも書かれていない区間がある）ときや、アプリが落ちたときは、今までどおり録音ファイルから文字起こしし直します

録音開始の画面で、授業ごとに次を選べます（前回の設定を覚えます）。

- **言語**：日本語／英語／日本語と英語。名前に「英語」「English」「PBE」などが入った授業は、最初から英語になります
  - **日本語と英語**（macOS 26 以降）：日本語と英語の2つで同時に認識し、区間ごとに確からしい方を残します。そのぶんMacの負荷は上がります
- **場所**：教室／オンライン。オンラインにすると、Zoom などで流れている音を、マイクを通さずMacの中から直接録って文字起こしします（macOS 14.2 以降。MixRec と同じ仕組み）。マイクの録音も続けます。初回は、システム設定 → プライバシーとセキュリティ →「画面収録とシステムオーディオ録音」で LectureRecorder をオンにしてください。教室の授業は「教室」のままで
- **字幕**：オフ／オン／日本語訳。オンにすると録音中、画面の下に字幕のウィンドウが出ます。ドラッグで移動、端をドラッグで大きさを変えられ、次回も同じ位置に出ます
  - 日本語訳（macOS 15 以降。Mac内で翻訳）：英語の授業と、日本語と英語の授業の英語の部分に、日本語訳を字幕の下に黄色で出します（日本語の授業には訳はつきません）。録音の途中でも、字幕ウィンドウの訳のボタンでつけたり外したりできます（つけると、それまでの字幕にもさかのぼって訳がつきます）。初回は翻訳用の言語データのダウンロードを求められます。うまくいかないときは、システム設定 → 一般 → 言語と地域 → 翻訳言語 から「日本語」と「英語」をダウンロードしてください

字幕は×で隠せて、メニューの「字幕を表示／字幕を隠す」で録音中いつでも出し入れできます（字幕を出していなくても文字起こしは続いています）。
動作の記録は `~/Library/Logs/LectureRecorder.log` に残ります。

## 時間割

- 授業名を入れたマスが登録されます（空欄は授業なし）
- 2コマ続きの授業は、同じ曜日の続くコマに同じ授業名を入れてください。録音は1コマごとに分け、回数も1コマで1回と数えます
- 「時限の数」と各時限の時刻も設定できます（全学期共通）
- 「学期」で学期ごとに時間割を切り替えられます。「＋ 新しい学期」で次の学期を追加し、学期が始まったら「この学期を録音に使う」→「保存」
- 回数・出席数は学期ごとに数えます

## 出席履歴

メニューの「出席履歴…」で、授業ごとの出席回数と「日付・時刻・時限・回数」の一覧が見られます。

- 録音を終了すると出席として記録します（同じコマを録り直しても1回。「録音を破棄」したものは数えません）
- 間違えた記録はゴミ箱ボタンで削除、名前を間違えて登録した授業は「この授業の記録を削除」で授業ごと削除できます
- アプリを使い始める前の分などは、下の「記録を追加」から足せます

## 保存されるファイル

保存先は、パソコン版のGoogleドライブがあれば `マイドライブ/LectureRecorder/Inbox`、なければ `書類/LectureRecorder/Inbox` です（メニューの「保存先フォルダを開く」で開けます）。
Googleドライブに複数のアカウントでログインしている場合は、メニューの「保存先フォルダを編集」でどのアカウントに保存するかを選べます。

ファイル名は `2026-10-07_1510_授業名.txt` の形で、先頭にこのような情報が入ります。

```
---
種別: 講義
学期: 2026年後期
授業: 経営学
回数: #3
時限: 4限
日付: 2026/10/07（水）
録音: 15:10〜16:50（100分）
---

（文字起こし本文）
```

2コマ続きの授業では `時限: 3限（2コマ続き）` のようになります。

## 注意

- **ふたを閉じるとMacがスリープして録音が止まります。** 録音中はふたを開けたままにしてください（画面を消しても自動スリープはしません）
- 録音は5分ごとに別のファイルに区切って保存します。電源が急に落ちるなどしても、失うのは最後の5分ほどだけで、残りは文字起こしされます
- 文字起こしに失敗したり、途中でアプリを終了したりした録音は、録音していないときに自動でやり直します（全部で5回失敗したら、自動ではやめます）
- メニューの「録音履歴…」で、これまでの録音と状態（録音中・文字起こし待ち・完了・できなかった など）を確認できます。文字起こしを開く、音声をFinderで表示、もう一度文字起こし、削除もここからできます
- 録音した音声は Mac 内（`~/Library/Application Support/LectureRecorder/audio`）に置かれ、文字起こし後14日で自動削除されます

## 設定・データの場所

`~/Library/Application Support/LectureRecorder/` に入っています。

| ファイル | 中身 |
|---|---|
| `config.json` | 時間割・時限の時刻・保存先など |
| `attendance.json` | 出席の記録 |
| `audio/` | 録音した音声（録音1回分ごとのフォルダに、5分ごとのファイル） |

`config.json` をテキストエディタで直接開いて、`outputFolder` にパスを書くと保存先を好きなフォルダに、`keepAudioDays` で音声を残す日数を変えられます（ふだんは触る必要はありません）。
